# NUMUe Bug Tracker

This repository is used to report and track bugs, issues, and inconsistencies found in the **NUMUe educational platform**.  
All reports are organized using GitHub Issues with structured templates to ensure clarity and consistency.

---

## 📌 Purpose

This repo helps the development team:
- Identify and track platform bugs
- Improve UI/UX issues
- Monitor AI and grading behavior
- Maintain structured QA reporting

---

## 🧪 How to Report a Bug

When creating an issue, please follow the provided template and include:
- Clear title
- Steps to reproduce
- Expected vs actual result
- Environment details
- Screenshots or evidence (if available)

---

## 🏷️ Labels System

We use labels to categorize issues:

### Severity
- `Severity: Critical`
- `Severity: High`
- `Severity: Medium`
- `Severity: Low`

### Priority
- `Priority: Urgent`
- `Priority: High`
- `Priority: Medium`
- `Priority: Low`

---

## 📂 Issue Types

- Bugs
- UI/UX Issues
- AI/Grading Issues
- Localization Issues
- Functional Issues

---

## 📍 Notes

- Please avoid duplicate reports
- Make sure steps are clear and reproducible
- Attach screenshots whenever possible
